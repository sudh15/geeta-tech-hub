What is a Case Converter?

A case converter transforms text between different letter cases. It supports uppercase, lowercase, title case, sentence case and programming formats like camelCase, PascalCase, snake_case and kebab-case.

How to Use

Type or paste your text above, then click any case button to convert. The result appears instantly and can be copied with one click.
