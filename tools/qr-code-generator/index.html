What is a QR Code?

A QR (Quick Response) code is a two-dimensional barcode that can store URLs, text, contact information, Wi-Fi credentials and more. QR codes can be scanned by any smartphone camera.

How to Use

Enter a URL or text, customize the size and colors if desired, then click "Generate QR Code". Download the result as PNG or SVG.
