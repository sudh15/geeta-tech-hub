What is Base64?

Base64 is an encoding scheme that converts binary data into ASCII text. It is commonly used in email attachments, data URLs, and API authentication headers.

How to Use

Enter your text and click "Encode" to convert to Base64. To decode, paste a Base64 string and click "Decode". Use "Swap" to move the output back to the input field.
